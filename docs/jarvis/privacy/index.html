Jarvis Read-Only Assistant

Privacy policy

Effective 24 November 2026. Operator: Chad Reddy.

Purpose and information accessed

Jarvis is a personal assistant for the owner's own Google accounts. With permission, this integration reads Gmail messages and associated information, and Google Calendar calendars and events. It uses that information only to provide the owner's personal mail review, schedule review and summaries. Client accounts and client material are outside this integration's intended use.

Read-only permissions

The integration uses gmail.readonly and calendar.readonly. These permissions do not allow it to send or change emails, or create, change or delete events. Google authorisation credentials enable access and are not published on this website.

Use and sharing

Mail and calendar information is private to the owner's assistant workflow. It is not shared with other users, published, sold, used for advertising or used to train general-purpose AI models. This public website does not receive that information.

To generate personal summaries, Jarvis sends mail and calendar content to Anthropic and OpenAI through their APIs. These providers process that content under their API terms, which do not use API customer content to train models by default. This processing is part of the owner's assistant workflow; otherwise the information is not shared.

Jarvis's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and deletion

Google remains the source of the mailbox and calendar. Assistant-generated summaries and any locally retained information are controlled by the owner. The owner can delete retained assistant copies and summaries through the operator; revoking Google access stops future access but does not itself delete existing copies.

Control and revocation

The owner can remove Jarvis's access from Google Account connections at any time. Doing so does not delete the owner's original Gmail messages or Calendar events.

This website

These are static information pages, with no analytics, cookies set by our code, forms or Google sign-in. GitHub hosts the pages and may process ordinary request information such as IP addresses under its privacy statement.

Contact

Contact Chad Reddy using the support email shown on the Google consent screen for private enquiries or deletion requests. For general questions, open a public support issue; never post private mail, calendar data or credentials there.
